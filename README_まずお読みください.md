# コメトピ7 v5.4 — 埋め込みレイアウト復元

v5.3を基準に、YouTube埋め込みの案内・重複ボタンだけを撤回し、v5.2で確認した通常の16:9 iframeプレーヤーに戻しました。

- 既存の「コメトピ7の動画を見る」と「このページで再生」は両方維持。
- ローカルfile://ではエラー153が出る可能性があります。表示を隠す回避処理は追加していません。
- 公開時はHTTPSサイトが Referer 情報を送信できるため改善が期待されますが、実際の再生はCloudflareで確認が必要です。
- iframeタグから直接表示する方式で、new YT.Player、playerVars、originの固定設定はありません。
- public/index.html の meta referrer（strict-origin-when-cross-origin）を維持。
- 検証用 /embed-test.html も保存しました。公開サイトで埋め込みテストしてください。
- 記事・動画紐付け、広告、SEO、管理者認証、カウンター、フォームは変更していません。

## 実行確認

`npm test` — 公開前のプログラムテスト。外部サービスと接続する統合試験ではありません。

本番公開後にChromeで「このページで再生」を選び、再生できるか確認してください。
